Identifiants

Les identifiants et mots de passe avec lesquels MarginMate se connecte pour récupérer vos factures et vos ventes. Ils sont chiffrés sur ce serveur, avec une clé que Windows réserve au compte qui fait tourner le serveur, jamais dans la base : ils ne partent ni dans un export « Données », ni dans une sauvegarde. Un mot de passe enregistré n'est jamais réaffiché ; laissez son champ vide pour le garder. Chaque mot de passe ne part que vers le site pour lequel il a été saisi.

Si le navigateur propose d'enregistrer ou de générer un mot de passe sur cette page, refusez : ce sont les mots de passe d'autres sites, pas celui de MarginMate.
