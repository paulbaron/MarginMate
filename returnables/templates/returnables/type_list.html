Comment une ligne de bon prend son type

Chaque ligne d'un bon prend le premier type, dans l'ordre ci-dessus, dont un motif se trouve dans sa désignation - actif ou non : désactiver un type l'ôte seulement du formulaire de reprise. Modifier un motif reclasse aussitôt toutes les lignes de tous les bons.

Un motif est une expression régulière : F[ÛU]TS?\b reconnaît « FÛT » et « FUTS ». Une ligne qu'aucun type ne reconnaît se classe depuis la page de son bon (« Classer comme »).
