Lire un format
  • Les colonnes se comptent à partir de 1, de gauche à droite : « Tester » les numérote.
  • Une ligne est une opération quand sa colonne de date contient une date du format ; les autres (en-tête, solde) sont passées.
  • Le montant : une colonne signée, négative quand l'argent sort, ou une colonne des débits et une des crédits.
  • Le numéro de compte est cherché au-dessus de la première opération ; (?P<compte>…) n'en garde qu'une partie.
  • Compte, dates, libellé et montant identifient une opération : lus autrement, les opérations déjà importées le seraient une seconde fois.
  • OFX et CAMT.053 : pas de colonnes. Le libellé est le nom et le mémo de l'opération (OFX), ou le libellé de la banque (CAMT.053) ; le type d'opération est son code (TRNTYPE en OFX, code ISO en CAMT.053) ; seuls les relevés en euros s'importent.
  • Changer de type de fichier pour un compte déjà importé : chaque opération serait lue autrement, et importée une seconde fois.
